# {{ project_title }}

Go GraphQL service generated by `golang-graphql-service-archetype`.

## Getting started

### Generate GraphQL server code

```bash
make generate
```

This runs `go generate ./...` (which invokes `gqlgen generate`) and produces `graph/generated.go` and resolver stubs.

### Build

```bash
make build
```

### Test

```bash
make test
```

### Run

```bash
make run
```

GraphQL endpoint on port `{{ service_port }}` at `/graphql`, HTTP management on `{{ management_port }}`.

## Schema

The GraphQL schema lives at `graph/schema.graphqls`.

After running `make generate`, uncomment the server wiring in `cmd/server/main.go` and implement the resolver methods in the generated `graph/*.resolvers.go` files.
